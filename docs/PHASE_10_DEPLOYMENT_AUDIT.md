# Phase 10 — Production hardening and deployment audit

**Assessment date:** 2026-11-25 (UTC)
**Branch:** `arena/e6c9b4f7-crownd-2-0`
**Baseline commit:** `36ef9b55d3e589bdf856e3e99c70342a14a69076` (Phase 9 completion). This audit records the current Phase 10 worktree; no Phase 10 commit, deployment, provider account, or production credential has been created.

## Scope and inspected architecture

Reviewed FastAPI configuration/startup/security/session handling, SQLAlchemy and Alembic revisions, API routers, worker/outbox and SMTP handling, Compose, backend/frontend Dockerfiles, Nginx, frontend bundling/API paths, dependencies, environment examples, ignore rules, backup/restore scripts and operational documentation.

Repository deployment model: PostgreSQL 16, FastAPI, separate SQL notification worker, Vite SPA served by Nginx, and Mailpit for local email capture. The preferred minimal provider-neutral production shape is HTTPS ingress/static frontend → API service(s) → persistent PostgreSQL, with a separately supervised worker, shared Redis for production rate limits, SMTP relay and provider-native logs/backups. A static host plus container application host is also possible. Redis/SMTP/hosting choices depend on deployment; no vendor, price, account or free-tier guarantee is assumed. No external service was accessed or deployment performed.

## Validation actually executed

- Backend: `pytest -q` — 74 passed, 1 upstream Starlette/httpx TestClient deprecation warning. Test fixture now uses a deterministic synthetic JWT key of sufficient length; no JWT key-length warnings remain.
- Frontend: `npm test -- --run` — 38 tests in 9 files passed; `npm run lint` passed; `npm run build` passed TypeScript and Vite.
- Security/dependencies: `pip-audit -r requirements-runtime.lock` and `pip-audit -r requirements.txt` — no known vulnerabilities; `npm audit --audit-level=high` — zero vulnerabilities. Scope/time is point-in-time.
- Python `compileall`, both backup scripts `bash -n`, PyYAML Compose parse (services: db, migrate, api, notification-worker, web, mailpit) and `git diff --check` succeeded.
- Not executed: Docker/Compose runtime/build, PostgreSQL server/migrations, encrypted backup/restore, production TLS/proxy/browser auth, live SMTP, hosted worker restart/liveness, production-like E2E, accessibility, load testing, deployment or provider verification. Tools are unavailable in this environment or external operations were explicitly out of scope.

## Overall assessment

Phase 10 provides practical configuration, container, health/logging, rate-limit, worker/email, dependency, backup-script, and documentation hardening. It is not a production certification. Local SQLite and source/YAML checks do not establish PostgreSQL or container correctness. **Production and staging deployment remain blocked** until database/migration, actual runtime, TLS/auth/browser, restore, worker/SMTP, monitoring, security/privacy and release gates are performed in a controlled environment. Do not deploy based solely on these changes or documentation.
